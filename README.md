# 🏸 バドミントン対戦組み合わせジェネレーター

バドミントンのダブルス練習で、対戦の組み合わせをスコアリング最適化で自動生成するWebアプリです。

## 機能

- **プレイヤー管理**: 追加・削除・途中参加・途中退出に対応
- **スタミナ設定**: 5段階で各プレイヤーの体力を設定し、出場頻度を自動調整
- **コート数設定**: 複数コートでの同時進行に対応
- **先読み生成**: 最大10ラウンド先まで一括生成
- **再抽選**: ラウンド単位で気に入らない組み合わせを再生成
- **手動編集**: プルダウンで各コートの選手を任意に差し替え可能
- **統計表示**: 出場回数・休憩回数・出場率を表示

## スコアリング基準

1. **ペア重複回避** — 同じペアで組む回数を分散
2. **対戦相手重複回避** — 同じ相手との対戦を分散
3. **連続出場回避** — 連続でコートに立たないようにする
4. **連続休み回避** — 連続で休憩しないようにする
5. **総試合数均等** — 出場率が全員均等に近づくようにする
6. **スタミナ適合** — スタミナ設定に応じた目標出場率に近づける
